# Menu design tokens

The web host's stylesheet is
[`frontend/assets/css/tokens.css`](../../frontend/assets/css/tokens.css).
It is loaded by `frontend/index.html` so the staged web package uses the same
tokens. Its baseline values are grouped from current checked-in styles; they
are not asserted to be Nintendo's official design tokens. Update this source
when shared colors, transitions, focus treatment or canvas dimensions change.
